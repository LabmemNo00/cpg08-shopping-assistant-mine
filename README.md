# CPG08 购物助手

**红薯账号判定违规，所以帖子和账号都暂无了，也没办法回复消息申诉中，这边功能还都正常，有问题可以联系红薯id 94986299720🥲**

面向 CPG08 漫展现场购物的单文件离线工具。它可以导入 CPP 心愿单导出的 Excel 文件，将想购买的同人本、周边等内容按摊位归类，并在 1–5 号馆示意地图上显示 Wishlist 摊位。

本工具分为 iOS 版和通用版：仅苹果手机和平板选择 iOS 版，其他设备均使用通用版。通用版由一个 HTML 文件组成，不需要安装软件，也不需要服务器。购物清单、价格、购买状态、垃圾桶和界面设置默认保存在当前浏览器中。iPhone 和 iPad 用户可通过 Safari 将 iOS 版添加到主屏幕后离线启动。

> 本项目是非官方现场辅助工具。场馆、设施和摊位位置均为便于辨认的相对位置示意，不按实际距离比例绘制；如现场信息发生变化，请以主办方最新公告和现场指示为准。

## 主要功能

- 导入 CPP 心愿单导出的 Excel 文件。
- 按摊位合并和展示 Wishlist，同一摊位只显示一次社团名称。
- 在 1–5 号馆地图中定位普通摊位、2 号馆创摊和 3 号馆企业摊位。
- 显示卫生间、咨询台、更衣室、寄包处、扶梯、相邻场馆和官方图中明确标出的出口。
- 通过场馆总览和摊位区导航快速跳转到详细地图。
- 搜索摊位、展品、社团、原作和类型。
- 在摊位详情中直接修改商品名。
- 将商品标记为“尚未购入”“已购入”或“已完售”。
- 记录单价、数量、已花金额和当前预计金额。
- 清单条目左滑进入垃圾桶，支持恢复或彻底删除。
- 导出和导入 JSON 备份。
- 自定义 Wishlist 地图标记透明度，默认 80%。
- 支持将苹果离线版添加为 iPhone 主屏幕 App，首次缓存完成后可离线启动。
- 通用版不依赖外部脚本、样式表或字体，可作为单个 HTML 文件离线使用。

## 快速开始

### 电脑和其他手机使用通用版

1. 下载 `index.html`，使用 Chrome、Edge、Safari 等现代浏览器打开。
2. 点击底部的“添加 / 导入”。
3. 导入 CPP 心愿单导出的 Excel 文件，或直接添加购物条目。
4. 返回“地图”查看对应摊位。
5. 出发前进入“添加 / 导入”，点击“导出 JSON”保存一次备份。

### iPhone 安装与离线使用

1. 首次安装时连接网络，使用 Safari 打开 [iPhone 离线版安装入口](https://riiiiiii.github.io/cpg08-shopping-assistant/index_ios.html)。
2. 打开右上角“设置”，等待“安装与离线”显示“缓存已就绪”。
3. 点击 Safari 的“分享”按钮，选择“添加到主屏幕”。
4. 回到主屏幕，从新生成的 `CPG08` 图标启动应用。
5. **从主屏幕 App 中**导入 Excel 或 JSON；不要先在 Safari 网页中录入正式数据。
6. 打开“设置”，确认状态显示“已安装 · 可离线”。
7. 开启飞行模式并彻底关闭应用，再从主屏幕图标重新打开一次；地图和清单应仍可使用。
8. 导出一份 JSON 备份后再前往现场。

> Safari 页面与添加到主屏幕后的 Web App 可能使用不同的本地数据空间。正确顺序是：**先添加到主屏幕，再从主屏幕 App 导入数据**。清理网站数据、删除主屏幕 App、移动到其他网址或更换设备前，请先导出 JSON 备份。

不要从 iPhone“文件”App 直接打开下载的 HTML 文件；该方式可能只显示静态预览，无法保证导入、保存和离线功能正常运行。

## 使用教程

### 1. 导入 Excel 心愿单

1. 打开底部“添加 / 导入”。
2. 在“从 Excel 导入”区域选择 CPP 心愿单导出的 Excel 文件。
3. 等待页面提示导入完成。
4. 切换到“地图”或“清单”检查结果。

程序会自动识别以下列：

| 列名     | 是否必需 | 用途               |
| -------- | -------- | ------------------ |
| 摊位号   | 是       | 决定场馆和地图位置 |
| 展品名称 | 是       | 购物条目的名称     |
| 类型     | 否       | 显示在条目详情中   |
| 热度     | 否       | 保留导入信息       |
| 筹备状态 | 否       | 显示在摊位详情中   |
| 原作     | 否       | 用于显示和搜索     |
| 社团名称 | 否       | 显示在摊位号后面   |

导入规则：

- 使用“摊位号 + 展品名称”作为匹配条件。
- 如果已经存在完全相同的摊位号和展品名称，将更新类型、热度、筹备状态、原作和社团名称。
- 已填写的价格、数量和购买状态会保留。
- 新导入的条目默认数量为 1，状态为“尚未购入”。
- 当前读取器面向 Excel 2007+ OOXML 工作簿。CPP 导出的文件即使扩展名显示为 `.xls`，只要内部是 OOXML 仍可读取；真正的旧式二进制 `.xls` 暂不支持。
- 如果导入失败，请检查表头名称、文件是否损坏，以及工作簿是否为受密码保护的文件。

### 2. 直接添加条目

1. 打开“添加 / 导入”。
2. 填写摊位号和展品名称，这两项为必填项。
3. 根据需要填写社团名称、价格和数量。
4. 点击“加入 Wishlist”。

添加成功后会自动切换到地图；如果摊位号能够识别，还会进入相应场馆。

支持的摊位号示例：

| 类型           | 示例             | 说明                                 |
| -------------- | ---------------- | ------------------------------------ |
| 普通摊位       | `壹S24`、`伍J23` | 使用中文馆号、英文大写排号和两位数字 |
| 连续摊位       | `壹S24-S25`      | 会按编号区间的中间位置标记           |
| 2 号馆创摊     | `创016`          | 显示在创摊矩阵的对应编号组           |
| 3 号馆企业摊位 | `CPC08`、`企09`  | 显示在企业摊位矩阵中                 |

建议保持 CPP 导出文件中的原始摊位号写法。普通摊位中的英文字母需要使用大写。

### 3. 使用场馆地图

地图顶部可切换“总览”和 1–5 号馆：

- “总览”显示各馆大致相对位置和 Wishlist 摊位数量。
- 点击场馆可以进入对应详细地图。
- 馆内的摊位区块可以点击，并自动滚动到相应的详细摊位排。
- 相邻场馆箭头可以直接切换场馆。
- 绿色箭头仅表示官方图中明确标注的出口。
- 设施图标表示官方图中能够明确定位的卫生间、咨询台、更衣室、寄包处和扶梯等设施。
- 2 号馆创摊和 3 号馆企业摊位使用矩阵表达相对位置。

地图颜色：

- 绿色：该摊位仍有待购条目。
- 蓝色：该摊位没有待购条目，所有条目均已处理。
- 灰色摊位排或矩阵格：当前 Wishlist 在该位置没有标记。

点击彩色摊位标记，可以打开该摊位的全部商品并修改状态、价格和数量。

### 4. 使用清单

清单按场馆、排号和摊位编号排序，并将同一摊位的商品归在一起。

- 使用顶部搜索框搜索摊位号、展品名称、社团、原作或类型。
- 使用右侧筛选器查看全部、待购、已购或完售条目。
- 点击摊位标题打开完整摊位详情。
- 在摊位详情中点击商品名右侧的编辑图标，可修改商品名；失焦或按回车后自动保存。
- 在价格输入框中补充或修改单价。
- 点击状态按钮可以依次切换“尚未购入 → 已购入 → 已完售 → 尚未购入”。
- 在摊位详情中可以直接选择状态、修改数量，并将该摊位所有待购条目一次性标记为已购。

页面顶部统计含义：

- “已花”：状态为“已购入”的条目金额之和。
- “当前预计”：除“已完售”外所有已填写价格的条目金额之和。
- “尚未购入”：当前仍处于待购状态的条目数量。
- 数量会参与金额计算，即“单价 × 数量”。

### 5. 删除、恢复与彻底删除

1. 在“**清单**”中按住**商品名**向左滑动；电脑上也可以按住并向左拖动。
2. 滑动超过触发距离后，条目会进入垃圾桶。
3. 点击右上角“设置”，在“垃圾桶”中选择“恢复”或“彻底删除”。

“彻底删除”无法撤销。需要长期保留的数据请先导出 JSON 备份。

### 6. 数据备份与恢复

#### 导出备份

1. 打开“添加 / 导入”。
2. 在“数据备份”区域点击“导出 JSON”。
3. 浏览器会下载 `CPG08_wishlist_backup.json`。

备份包含购物条目、状态、价格、数量、垃圾桶和地图透明度设置。

#### 恢复备份

1. 打开“添加 / 导入”。
2. 点击“导入 JSON”。
3. 选择此前导出的 `CPG08_wishlist_backup.json`。

导入 JSON 会用备份内容恢复当前应用状态。建议在恢复前先导出当前数据，以免误覆盖。

#### 恢复初始数据

“恢复为初始 Wishlist”会清除当前条目、购买状态、价格和垃圾桶，并恢复为两个测试条目：

- `test1`：`壹S24`
- `test2`：`壹S25`

两个测试条目的社团名称均为 `AAA测试`。地图标记透明度设置会保留。

### 7. 调整地图标记透明度

1. 点击右上角“设置”。
2. 调整“摊位标记透明度”滑块，可选范围为 20%–100%，步长为 5%。
3. 默认值为 80%。

该设置只影响 Wishlist 彩色摊位标记；设施、摊位区导航和基础地图保持清晰。点击或聚焦摊位标记时，该标记会暂时以完全不透明方式显示。

## 数据保存与隐私

- 应用不会主动将 Wishlist 上传到服务器。
- 数据保存在当前浏览器或主屏幕 App 的本地存储中。
- 不同浏览器、不同设备或不同打开地址通常拥有独立的数据空间。
- iPhone Safari 页面与从主屏幕启动的 Web App 也可能拥有相互独立的数据空间。
- 无痕模式、清理站点数据、卸载浏览器或系统存储回收都可能导致数据丢失。
- Excel 文件只在当前设备的浏览器中解析。
- 出发前、删除主屏幕 App、清理浏览器数据或更换设备前，请导出 JSON 备份。

iPhone 离线版只在首次安装和准备缓存时需要网络，Wishlist 不会被同步或公开。离线缓存就绪后可以从主屏幕断网启动；首次安装完成后，请务必用飞行模式测试一次。

## 已知限制

- 地图是现场购物辅助示意，不提供实时定位和路线规划。
- 设施与摊位区按相对位置绘制，不代表实际距离。
- 只内置 CPG08 当前整理的 1–5 号馆、创摊和企业摊位布局。
- 不能读取真正的旧式二进制 `.xls` 工作簿。
- 不支持密码保护的 Excel 文件。
- 数据不会自动跨设备同步。
- 删除主屏幕 Web App、清理网站数据或更换发布网址可能清除或隔离现有数据。
- 未提供云端账户、多人协作或在线数据库。
